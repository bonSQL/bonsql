# Reporting a security problem

If you find a security problem in bonSQL, please do not open a public issue. Send the details to
bonsql@whconsulting.fr and you will get a reply within a few days. Problems in the database servers
themselves, or in the libraries bonSQL includes (listed in THIRD-PARTY-NOTICES.txt), should go to their
own projects.

You can also use GitHub's private reporting: https://github.com/bonSQL/bonsql/security/advisories/new.
Either way, nothing is published until a fix is out.
