# Contributing

Thank you for your interest in bonSQL.

**Bug reports and feature requests are welcome**: open an [issue](https://github.com/bonSQL/bonsql/issues/new/choose).
Say which server (MariaDB or MySQL, and its version), which bonSQL version (Help > About), what you did, what
you expected and what happened instead. For anything security-related, see [SECURITY.md](SECURITY.md) rather
than a public issue.

**Code changes are not being accepted at the moment.** bonSQL is maintained by one person and the code is
still being reorganised; pull requests will be closed without review until that changes. This file will say so
when it does. The source is published because the GNU GPL requires it and so that anyone can build, study and
fork it; forks are of course free to go their own way under the same licence.
